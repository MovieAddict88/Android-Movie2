# School Setup Guide (30-Minute Onboarding)

## 1. District Registration (5 mins)
- Super Admin creates the District account.
- Define the base subdomain (e.g., `springfield.schoolconnect.com`).

## 2. School Configuration (10 mins)
- School Admin uploads the school logo.
- Configure custom behavior categories (e.g., "Eagle PRIDE points").

## 3. Data Import (10 mins)
- Upload Teacher and Student rosters via CSV.
- System automatically generates invite codes for parents.

## 4. Training (5 mins)
- Send the "Teacher Quick Start" PDF to staff.
- Teachers log their first behavior using the 2-tap widget.
